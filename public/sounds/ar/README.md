# ملفات النداء الصوتي (احتياطية)

شاشة الانتظار (`/display`) تنطق الرقم بصوت المتصفح العربي إن وُجد (Edge على ويندوز فيه أصوات عربية، وأندرويد TV مع Google TTS).
إذا لم يوجد صوت عربي في جهاز الشاشة، تُستخدم هذه الملفات المسجلة، وتُركّب منها الجملة: «الرقم» + العدد + «تفضل».
الملفات لم تُسجَّل بعد. حتى تُضاف مع `manifest.json` تعمل الشاشة بالنغمة فقط عند غياب الصوت العربي.

## المطلوب (40 ملفاً، mp3 قصير، صوت واحد واضح، بلا صمت في البداية والنهاية)

| الملف | يُقال |
|---|---|
| `raqm.mp3` | الرقم |
| `tafaddal.mp3` | تفضل بالدخول |
| `wa.mp3` | و |
| `u0.mp3` … `u9.mp3` | صفر، واحد، اثنان، ثلاثة، أربعة، خمسة، ستة، سبعة، ثمانية، تسعة |
| `u10.mp3` … `u19.mp3` | عشرة، أحد عشر، اثنا عشر، ثلاثة عشر … تسعة عشر |
| `t2.mp3` … `t9.mp3` | عشرون، ثلاثون، أربعون، خمسون، ستون، سبعون، ثمانون، تسعون |
| `h1.mp3` … `h9.mp3` | مئة، مئتان، ثلاثمئة، أربعمئة، خمسمئة، ستمئة، سبعمئة، ثمانمئة، تسعمئة |

مثال: 125 = `raqm` `h1` `wa` `u5` `wa` `t2` `tafaddal` (الرقم مئة وخمسة وعشرون، تفضل بالدخول).

## التفعيل

بعد وضع الملفات هنا، أنشئ `manifest.json` بأسماء الموجود منها:

```json
{ "ext": "mp3", "files": ["raqm", "tafaddal", "wa", "u0", "u1", "u2", "u3", "u4", "u5", "u6", "u7", "u8", "u9", "u10", "u11", "u12", "u13", "u14", "u15", "u16", "u17", "u18", "u19", "t2", "t3", "t4", "t5", "t6", "t7", "t8", "t9", "h1", "h2", "h3", "h4", "h5", "h6", "h7", "h8", "h9"] }
```

اسم الطبيب لا يُنطق في هذا الوضع (لا يمكن تسجيله مسبقاً)، ويظهر مكتوباً على الشاشة.
